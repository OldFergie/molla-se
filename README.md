# molla.se

Källkoden till [molla.se](https://molla.se).

- Sidan är statisk HTML/CSS/JS i `index.html`.
- Varje push till `main` publiceras automatiskt via GitHub Pages (`.github/workflows/pages.yml`).
- Domänen ligger hos Loopia och pekar på GitHub Pages (se `CNAME`).
- Texter och bilder ändras via adminpanelen på [molla.se/admin](https://molla.se/admin). Se `ADMIN.md`.
